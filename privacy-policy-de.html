2. WELCHE DATEN ICH SAMMLE UND WARUM

Die Verarbeitung ist unterschiedlich für kostenlose und Premium-Nutzer:

A) FÜR ALLE NUTZER (kostenlos und Premium):

  • Automatische technische Daten: Gerätetyp, Betriebssystem, App-Version, anonymisierte IP-Adresse, Nutzungszeiten, verwendete Funktionen. Diese Daten identifizieren Sie nicht persönlich.
  • Daten für Werbung (nur kostenlose Version): Die App zeigt Werbung über Google AdMob und Meta Audience Network. Zur Anzeige relevanter Werbung können die Werbe-ID des Geräts (AAID/IDFA) und allgemeine Nutzungsdaten erhoben werden. Die Personalisierung von Werbung kann in den Geräteeinstellungen deaktiviert werden.
  • Geräteberechtigungen:
    • Speicher/Fotos (optional): Erforderlich zum Speichern der PDF-Angebote auf Ihrem Gerät und zum Teilen (WhatsApp, E-Mail usw.) sowie zum Hinzufügen eines Logos aus der Galerie oder Kamera. Die als Logo verwendeten Fotos werden NIE auf unsere Server hochgeladen oder in der Cloud gespeichert; sie werden nur lokal zur Generierung der PDF-Datei verwendet.

B) NUR PREMIUM-NUTZER:

  • Konto: Um Angebote in der Cloud zu speichern und zwischen Geräten zu synchronisieren, müssen Sie ein Konto mit einer E-Mail-Adresse erstellen. Wir speichern nur die E-Mail für den Zugriff.
  • Angebotsdaten (von IHNEN freiwillig bereitgestellt): Wenn Sie ein Angebot erstellen und es in der Cloud speichern möchten, werden die von Ihnen eingegebenen Daten auf den sicheren Servern von Google Firebase (Firestore) gespeichert. Diese können enthalten:
    • Ihre Informationen: Name, Vorname, Telefonnummer, USt-IdNr., RUT (Chile), CUIT/CUIL (Argentinien), Firmen-E-Mail, Logo.
    • Kundeninformationen: Name, Vorname, Telefon, USt-IdNr./RUT/CUIT, Adresse.
    • Angebotsdetails: Dienstleistungen, Preise, Umsatzsteuer, Notizen.

C) NUR PREMIUM-NUTZER (KI- und Sprachassistent-Funktionen):

  • Sprachaufnahmen (temporär): Wenn Sie die KI-Sprachassistent-Funktion nutzen, wird Ihre Stimme vorübergehend aufgezeichnet und transkribiert, um Ihre Anfrage zu verarbeiten.
    • Audioaufnahmen werden NICHT gespeichert und werden unmittelbar nach der Transkription gelöscht
    • Nur der transkribierte Text wird zur Verarbeitung an die KI gesendet
    • Die Sprachaufnahme wird nur aktiviert, wenn der Benutzer freiwillig auf die Aktivierungstaste des Sprachassistenten klickt
    • Die Aufnahme wird automatisch nach 30 Sekunden Inaktivität beendet oder wenn der Benutzer sie manuell unterbricht
  • Mikrofon (optional): Ausschließlich für die KI-Sprachassistent-Funktion erforderlich. Das Mikrofon wird nur aktiviert, wenn der Benutzer die Sprachaufnahme freiwillig startet. Keine Aufnahme erfolgt ohne Ihre ausdrückliche Zustimmung und freiwillige Handlung.
Wichtig: Als KOSTENLOSER Nutzer verlassen keine persönlichen Daten Ihr Gerät. Alles wird lokal gespeichert (lokaler Speicher) und nur Sie haben Zugriff darauf.

5. KÜNSTLICHE INTELLIGENZ (KI) - GOOGLE GEMINI

Die App bietet eine optionale Funktion zur KI-Analyse von Angeboten und Preislisten über die Google Gemini API (Google-Künstliche-Intelligenz-Dienst).

Was an die KI gesendet wird:

  • Preise und Beschreibungen der in das Angebot/die Preisliste eingegebenen Arbeiten
  • Erkannter Wirtschaftszweig (z.B. Bau, Sanitär, Elektriker)
  • Vom Benutzer ausgewähltes Land und Währung
  • Zahlen und Mengen der Arbeiten (nur für Analysezwecke)

Was NIE an die KI gesendet wird:

  • Personenbezogene Daten (Name, Vorname, E-Mail, Telefon, USt-IdNr., Adresse)
  • Kundendaten (Name, Telefon, Adresse)
  • Geografische Koordinaten oder genauer Standort
  • Zahlungsdaten oder sensible Finanzinformationen
  • Geräte-ID oder eindeutige Kennungen
  • Audioaufnahmen (nur der transkribierte Text wird gesendet)

Wie es funktioniert:

  • Die KI-Analyse ist nur für Premium-Nutzer (nach dem Kauf des Abonnements) verfügbar
  • Der Benutzer muss aktiv auf den Button "Mit KI analysieren" klicken
  • Keine automatische Analyse wird ohne Ihre ausdrückliche Zustimmung durchgeführt
  • Die Analysen werden in Echtzeit verarbeitet und nicht von Google Gemini gespeichert
  • Nur anonyme Logs (Datum, Anzahl der Anfragen, Erfolg/Fehler) werden zur Verbesserung des Dienstes gespeichert

Wo die Daten verarbeitet werden:

Die Anfragen an die KI werden über Google Cloud Functions und die Google Gemini API verwaltet, die Daten auf Servern in folgenden Regionen verarbeiten können:

  • Vereinigte Staaten (Region us-central1, Iowa)
  • Europa (Region europe-west3, Frankfurt) - bevorzugt für Nutzer in der EU/EWR/UK/Schweiz

Die Datenübertragungen in die USA erfolgen in Übereinstimmung mit den Standardvertragsklauseln (SCC) der Europäischen Kommission und dem Data Privacy Framework EU-USA.

Einschränkungen:

  • Die KI-Analysen sind auf 5 in den ersten 7 Tagen von Premium beschränkt, danach 50 pro Monat
  • Das Limit wird automatisch jeden Monat zurückgesetzt
  • Sie können direkt in der App sehen, wie viele Analysen Ihnen noch zur Verfügung stehen

Deaktivierung:

Die KI-Funktion ist völlig optional. Wenn Sie sie nicht nutzen möchten, klicken Sie einfach nicht auf den Button. Die App funktioniert ohne die KI-Analyse normal weiter.

Weitere Informationen:

Für Details darüber, wie Google Daten verwaltet, wenn Sie Gemini verwenden, lesen Sie:

  • Datenschutzerklärung von Google
  • Datenverarbeitungsbedingungen von Google Cloud

9. DATENSICHERHEIT

Wir implementieren technische und organisatorische Maßnahmen zum Schutz Ihrer Daten:

  • Firebase Security Rules: Datenzugriff nur für autorisierte Benutzer
  • Verschlüsselung: Daten während der Übertragung (HTTPS/TLS) und im Ruhezustand (Firestore-Verschlüsselung)
  • Eingeschränkter Zugriff: Nur ich (Alessio Di Pede) habe administrativen Zugriff
  • Regelmäßige Risikobewertung und angemessene Maßnahmen
  • Verschlüsselte Backups auf sicheren Servern

Jedoch ist kein System zu 100 % immun. Im Falle einer Datenschutzverletzung, die ein Risiko für Ihre Rechte darstellt:

  • DSGVO: Meldung an die Aufsichtsbehörde innerhalb von 72 Stunden und an Sie ohne unangemessene Verzögerung
  • LGPD: Mitteilung an die ANPD und die Betroffenen in "angemessener Zeit"
  • POPIA: Meldung an den Information Regulator und die Betroffenen unverzüglich
  • Argentinien: Meldung an die Dirección Nacional de Protección de Datos Personales

14. SO LÖSCHEN SIE IHR KONTO UND IHRE DATEN

Sie haben das Recht, Ihr Konto und alle zugehörigen Daten jederzeit zu löschen. So können Sie vorgehen:

Methode 1: Löschung direkt in der App (Empfohlen)

  1. Öffnen Sie die App "How Much - Angebote" auf Ihrem Gerät
  2. Gehen Sie zu Einstellungen → Profil
  3. Tippen Sie auf den Button "Konto löschen"
  4. Bestätigen Sie Ihre Wahl durch Eingabe des Passworts (falls erforderlich)
  5. Das Konto und alle zugehörigen Daten werden dauerhaft gelöscht

Löschfristen:

  • Daten in Firebase Firestore: Sofortige Löschung aus der Datenbank
  • Firebase Authentication-Konto: Sofortige Löschung
  • Backups: Vollständige Entfernung innerhalb von 30 Tagen

Wenn Sie keinen Zugriff auf die App haben, können Sie eine Löschungsanfrage per E-Mail senden an:

howmuch.preventivi@gmail.com

Geben Sie in der E-Mail die mit Ihrem Konto verbundene E-Mail-Adresse an.

Methode 3: Direkter Link (nur für Benutzer mit Zugriff auf die App)
